Automatic Backup Communication

ElectroSDM modules primarily communicate over your local Wi-Fi network using MQTT.

If the Wi-Fi network becomes unavailable, compatible modules automatically switch to ESP-NOW communication. This allows essential commands to continue working locally without relying on the Wi-Fi network.

Once Wi-Fi is available again, communication automatically switches back to MQTT without any user interaction.

This helps keep wall switches and essential automation functions operational during temporary Wi-Fi interruptions.

Power Supply Recommendation

ElectroSDM Light Modules operate on a stable 5V DC power supply. You may use any high-quality 5V power supply with sufficient current capacity.

Recommended ElectroSDM Power Supply

For the easiest installation we recommend using an optional ElectroSDM DIN Rail Power Supply. These power supplies are selected and tested specifically for ElectroSDM systems and simplify wiring inside the electrical cabinet.
