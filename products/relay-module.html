Power Supply Recommendation

The ElectroSDM Light Module operates from a stable 5V DC power supply. Any high-quality 5V power supply with sufficient current capacity can be used.

Recommended ElectroSDM Power Supply

For the easiest installation we recommend an optional ElectroSDM DIN Rail Power Supply. It is selected and tested specifically for ElectroSDM systems, simplifying installation inside the electrical cabinet.

Estimated Recommendations

  • Up to 4 Light Modules → 5V / 4A
  • Up to 10 Light Modules → 5V / 8A
  • Up to 15 Light Modules → 5V / 12A
  • Up to 20 Light Modules → 5V / 16A

These values are preliminary estimates and may change after additional hardware testing.

Purchasing an ElectroSDM power supply is completely optional. Any reliable 5V power supply with enough current capacity will work correctly.

Relay Outputs

The ElectroSDM Light Module includes five independent relay outputs.

Every relay can be configured independently and assigned to switches, automations, scenes or schedules.

Each relay is rated for 250V AC / 16A, making it suitable for most residential lighting and switching applications.

Always ensure that connected loads remain within the maximum electrical specifications and comply with local electrical regulations.

×

Smart Communication

ElectroSDM modules normally communicate through your local Wi-Fi network using MQTT.

If the Wi-Fi network becomes unavailable, compatible ElectroSDM modules automatically switch to ESP-NOW.

This allows essential communication between switches and Light Modules to continue, helping keep your lighting operational even during temporary Wi-Fi interruptions.

Once the Wi-Fi network becomes available again, every module automatically returns to MQTT communication without requiring any user action.

×

Automatic OTA Updates

ElectroSDM is designed to automatically keep every module up to date with the latest firmware.

The ElectroSDM Server periodically checks for available firmware updates. When a newer version is detected, compatible modules can update directly through the local network.

The current development version compares firmware versions with information published on a GitHub repository. This feature is still under development while the public firmware repository is being prepared.

Once released, firmware updates will be delivered automatically through the ElectroSDM Server, allowing secure and convenient updates without removing modules from the electrical cabinet.
